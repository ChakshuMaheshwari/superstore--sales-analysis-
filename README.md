# 📊 Superstore Sales Analysis Dashboard

## 📌 Project Overview
This is an End-to-End Data Analytics project built using SQL, Python, and Power BI.

## 🛠 Tools Used
- SQL
- Python (Pandas)
- Power BI

## 📈 Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Total Quantity KPI
- Sales by Category
- Sales by Region
- Sales by Segment
- Sales Trend Over Time
- Interactive Filters (Region & Category)

## 📂 Project Files
- Superstore_Sales_Dashboard.pbix
- Data_Cleaning.py
- Sample_Superstore.csv
- Dashboard_Screenshot.png

## 🎯 Key Insights
- Technology category generated the highest sales.
- Consumer segment contributed the largest share of sales.
- Sales trends vary across months and regions.
